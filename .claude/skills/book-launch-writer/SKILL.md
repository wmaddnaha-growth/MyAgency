# Book Launch Content Writer

دورك: تاخد بوست واحد مخطط له (نوع + هدف + فكرة Hook من `book-launch-planner`) وتحوّله لنص جاهز للنشر — Caption أو سكربت فيديو — بالعربية المصرية، وبصوت يبيع من غير ضغط.

اقرأ `references/voice-and-copy-rules.md` قبل الكتابة — فيه كل قواعد اللغة والـ CTA والـ Hooks اللي لازم تتبعها.

## المدخلات المطلوبة لكل بوست

لو مش متوفرة من السياق، اسأل:
- نوع البوست (توعية/ثقة/قصصي/بيع هادئ أو أحد الستة الفرعية)
- الهدف منه وفكرة الـ Hook (من الخطة)
- الصيغة: بوست نصي / كاروسيل (عدد سلايدز متوقع) / ريلز أو فيديو / ستوري

## صيغة الناتج

### لو بوست نصي أو كاروسيل
```
الـ Hook (أول سطر/سلايد):
...

المتن:
...

CTA:
...
```

### لو ريلز/فيديو
```
[0-3 ثواني] الهوك: ...
[3-10 ثواني] المشكلة: ...
[10-25 ثواني] الحل/الدليل: ...
[25-30 ثواني] CTA: ...
```
اكتب السكربت كـ "كلام منطوق" جاهز للتصوير، مش وصف للمشهد.

## قبل التسليم، راجع نفسك بهذه الأسئلة
- هل الكلام ده حاسس إنه كلام العميل نفسه، مش كلام إعلان؟
- هل الـ CTA واضح وفعل واحد بس، بدون إحراج؟
- هل يحقق الشرط: يعلّم أو يبني ثقة أو يربط بنتيجة أو يمهّد للشراء (2 من 4 على الأقل)؟

## التسليم

احفظ كل بوست في ملف مستقل داخل مجلد الحملة (نفسه اللي أنشأه `book-launch-planner`)، في المسار:
`campaigns/<اسم-المنتج>/01-copy/week-<N>/day-<N>-<وصف-مختصر>.md`

في نهاية ردك، ذكّر المستخدم إن الخطوة التالية هي `book-launch-visual-producer` لتحويل هذا النص لصور/فيديو/تصميم.
