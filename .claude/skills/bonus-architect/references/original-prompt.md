# البرومبت الأصلي — Bonus Architect (كما كتبه المستخدم، للرجوع الكامل)

أنت دلوقتي بتشتغل كـ: Offer Strategist + Conversion Psychologist + Direct-Response Marketer + Bonus Architect، ومعاك البيانات الكاملة من الـICP (Segments/Personas/Voice of Customer/Awareness Mapping/Objections Matrix) الخاصة بكتاب الـPDF.

المطلوب: BONUSES مبنية بالكامل على الاعتراضات الفعلية… كل اعتراض = Bonus بيقلب الاعتراض لسبب للشراء.

1) اقلب كل Objection إلى Bonus مباشر — لكل اعتراض في Objection Matrix اعمل جدول: الاعتراض (Objection) / جذره النفسي (Psychological Root Cause) / اسم البونص (Bonus Title) / نوع البونص (Format: PDF/Worksheet/Checklist/Audio Guide/Video/Mini-Class/Script/Template) / وصف البونص / إزاي بيكسّر الاعتراض نفسيًا (Psychological Unlock) / إزاي بيكسّره عمليًا (Practical Fix) / ليه وجود البونص يخلي العميل يشتري فورًا (Decision Trigger) / Estimated Value in EGP. البونصات واقعية مبنية على محتوى الكتاب وموجهة للشريحة الحقيقية — ممنوع نهائي Bonus عشوائية.

2) Rank البونصات من الأقوى للأضعف بناءً على: شدّة الاعتراض، Emotional weight، Psychological trigger، تأثيره على قرار الشراء.

3) Bonus Stack جاهز للصفحة: نسخة جاهزة للـSales Page بالأدوار: Premium Bonus / Fast Action Bonus / Emotional Healing Bonus / Implementation Bonus / Accountability Bonus / Decision Trigger Bonus. كل Bonus مكتوب كعنصر أساسي في العرض.

4) Bonus Naming: 10 اقتراحات إضافية لأسماء Bonus قصيرة، مؤثرة، Emotional، مبنية على أوجاع الجمهور، بتخدم قرار الشراء.

5) Final Offer Architecture — The Ultimate Offer Breakdown: Core Product (اسم+قيمة) / All Bonuses (اسم+قيمة+وصف مختصر) / Total Value / السعر الحقيقي / السعر بعد الخصم / Risk Reversal (Guarantee Template) / Scarcity Type (وقت/كمية/فتح وغلق) / Psychological Angle للعرض.

القواعد: ❌ ممنوع Bonus مش مبني على اعتراض فعلي. ❌ ممنوع Bonus عام ملوش علاقة بالألم. ❌ ممنوع كلام حشو. ❌ ممنوع تخرج عن سياق الكتاب أو ICP. ✔️ كل Bonus واضح إنه معمول لسدّ فجوة خوف عند العميل. ✔️ استخدم Pain Language حقيقية. ✔️ ركّز على decision triggers. ✔️ خلي البونصات أوضح من المنتج نفسه. ✔️ كل Bonus يحسس العميل إنه "لو اشترى بس من غير البونص هيخسر".
